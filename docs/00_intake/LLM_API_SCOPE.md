# Скоуп LLM / embeddings API (Hack&Change × ПСБ)

> Источники: `ПСБ_кейс.pdf` (§Формат сдачи, §Ограничения), Технический регламент §6–7, скрин биллинга Yandex Cloud (грант 4 000 ₽, 2026-11-09).

## Online auto-eval (`solution.py` на платформе)

| Компонент | Обязательно |
|---|---|
| Генерация | **DeepSeek V4.1 Flash** через прокси организаторов (`LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` из env) |
| Embeddings | **BAAI/bge-m3** (тот же локальный OpenAI-совместимый прокси) |
| Rerank | **Qwen3 Reranker 8B** — опционально |
| Свои ключи | **Не нужны** и не подставлять |

Цитаты:

- Кейс: «При запуске решений на платформе хакатона будет использоваться единая модель DeepSeek V4.1 Flash.»
- Кейс: «Для создания эмбеддингов на платформе доступна модель BAAI/bge-m3.»
- Регламент: «Участникам не нужны собственные API-ключи. Для генерации, эмбеддингов и реранжирования используется один локальный OpenAI-совместимый прокси».

## Локальная разработка / тестирование

Кейс §Ограничения 01: «При разработке и локальном тестировании решения участники могут использовать любые доступные им языковые модели.»

→ **Да**: Yandex Cloud / YandexGPT, OpenRouter и аналоги — для local/dev.  
→ Embeddings локально лучше держать **BGE-M3**, чтобы индекс совпадал с платформой.

## Финальный прототип (веб-UI / Docker)

Кейс §Формат сдачи: «Для генерации ответов при автоматической проверке и в финальном прототипе используется одна и та же языковая модель, указанная в Техническом регламенте.»

→ Основная генерация демо = **DeepSeek V4.1 Flash** (паритет с судьёй), не YandexGPT как primary.  
→ Внешние API в репо допустимы как конфиг (`.env.example` + README), но не как подмена модели судье и не как live-юрбазы.

## YandexGPT / Yandex Cloud AI

| Контур | Генерация | Embeddings |
|---|---|---|
| `solution.py` / online | ❌ нет (только DeepSeek платформы) | ❌ нет (только BGE-M3 платформы) |
| Local/dev | ✅ можно | ⚠️ можно, но риск рассинхрона индекса с сабмитом |
| Финальный прототип (основной путь) | ❌ не как основная LLM | предпочтительно BGE-M3 |

Грант ~4 000 ₽ на Yandex Cloud **не открывает** право подменить модели на платформе.

## Критично: корпус ответов

Независимо от провайдера LLM:

- Кейс: «Использовать внешние источники для формирования ответов нельзя.»
- Кейс / регламент: «Использовать внешние источники и собственные знания модели для обоснования юридических утверждений нельзя.»
- Только предоставленная KB организаторов; без live Гарант / Консультант / web legal DB.

## Практика: грант vs платформа

1. **Сабмит и демо-путь судьи** — платформенный DeepSeek + BGE-M3 (бесплатно на проверке, без своего ключа).  
2. **Грант Yandex** — опционально только local/dev или не-LLM инфраструктура; не тратить на «другую» модель для скора.  
3. OpenRouter / Yandex local — ок для итераций промптов; перед сабмитом прогон на DeepSeek + BGE-M3.
