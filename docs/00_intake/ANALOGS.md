# Аналоги — изучение, не копипаст

> Правило: сильное → слабое → что берём → чем превосходим.  
> Полные чужие продукты не переносим.

| Аналог / паттерн | Сильное | Слабое / ошибка | Берём | Превосходим в нашем MVP |
|---|---|---|---|---|
| Grounded legal research assistants (RAG + refuse) | Ответ только из корпуса; отказ если пусто | Часто «мягкий» отказ без указания дыры | Fail-closed: нет evidence → abstain | Явно писать, **какой** информации не хватает |
| Citation-grounding pipelines (retrieve → cite → validate) | Программная проверка цитат, не «поверь модели» | +latency, ломается на paraphrase | Gate: claim ↔ span match / id check | Показывать span в UI в 1 клик |
| Open legal agents with states `grounded / limited / abstain` | Явная машина состояний ответа | Сложная схема, overkill для хакатона | 3 состояния ответа в API | Простой JSON-контракт под судью и UI |
| Типичные «ChatGPT + PDF» хакатон-боты | Быстрый старт | Выдуманные статьи, нет редакции/даты | Не повторять | Редакции, доп. соглашения, роль, off-topic |
| Корпоративные knowledge bots без юридической дисциплины | Удобный чат | Нет аудита ссылок | UX чата + превью документа | Юр. политика отказа и анти-jailbreak |
| **NeuroLegal / Яндекс Нейроюрист** ([neurolegal.ya.ru](https://neurolegal.ya.ru/), лендинг + in-app `/expert/*`) | Сильный B2B LegalTech; **цитаты/ссылки**; «умные папки» (= projects); чаты внутри проекта; каталог **flows** = готовые команды/нейросценарии; Word; дисклеймер «не замена»; on-prem | In-app за **Яндекс ID**; широкий generative-скоуп + **Гарант**/веб; нет явного fail-closed abstain; фиолетовый SaaS — не клонировать | Цитата из своей БЗ; framing корпуса; дисклеймер; *опционально* лёгкий каталог типовых запросов **после** verify | RAG-only KB кейса; программный verify + missing; статусы ответа в UI; span-панель «Подтверждения» |

### In-app live UI (pixel-audit 2026-11-09)

#### Оболочка / sidebar (все `/expert/*`)
- Слева: логотип **Нейроюрист** → **Главная** / **Готовые команды** / **Умные папки** → **Создать чат** → список недавних чатов (усечённые заголовки).

- Тема: тёмный фон, фиолетовые акценты (не клонировать под ПСБ).

#### Умная папка / project chat (3 колонки)
Наблюдено на `…/projects/61ed4d5b…/chats/049a49ea…` («Как пользоваться Нейроюристом»):
- **Средняя колонка:** заголовок папки; счётчик **«Источники 9/999»**; **Поделиться папкой**; вкладки **Источники | Чаты**.
- **Источники:** «+ Добавить источники»; чекбоксы на каждый файл/ссылку (в shared-папке — readonly); смесь ссылок «Яндекс Нейроюрист» + PDF (`Быстрый старт`, `Готовые команды`, `Чаты и проекты`, `Настройки поиска`, `О сервисе`, `Подписка…` и т.п.).
- **Чаты:** список чатов папки + «Создать чат»; клик открывает тред справа.
- **Правая колонка (чат):** placeholder **«Спрашивайте по источникам»**; иконки режима (глобус / «рассуждения» / вложение — по UI); follow-up чипы; copy / 👍 / 👎; дисклеймер в футере.
- Онбординг-модалка «Что такое умные папки?» (Далее / Закрыть) — поверх workspace при первом заходе.

#### Обычный / generative chat (2 колонки)
Наблюдено на chat «Действуй как опытный I…» (`…/projects/b0100f8c…/chats/…`):
- Placeholder: **«Юридический поиск, анализ и формулировки»**; «+» и send.
- Ответ: длинный markdown / черновик документа с плейсхолдерами `[ВСТАВИТЬ: …]`.
- **Цитаты inline:** синие ссылки на нормы (`ст. 1228`, `ГК РФ`, ФЗ, кодексы) — классы `quote-group-trigger` / `source-summary-trigger`.
- Кнопка **«Раскрыть цитату»** у групп цитат; клик → **dialog «Источник»**: заголовок нормы + **span-текст** (пример: «Произведение, созданное в соавторстве, используется соавторами совместно.»).
- В конце ответа блок **«Ссылки»** (список полных наименований НПА); также секции «Анализ» / «Итоговый ответ».
- Chrome сообщения: **copy / like / dislike**; кнопка **«План действий»**.
- **Follow-ups:** 3 крупных чипа с уточняющими вопросами.
- Следы пайплайна в истории (не отдельный live-спиннер в момент съёмки, но тексты шагов в треде): «Суммаризация запроса» → «Анализирую тип запроса» / «Классифицирую запрос» → «Ищу подходящие источники» / «Собираю информацию из открытых источников» → «Готовлю ответ…» → **«Ответ найден в [областях права]»** (напр. интеллектуальная собственность, информационное / трудовое право).
- **Не наблюдалось** в этой сессии: явный fail-closed abstain / empty refuse UI; полноценный side-drawer Гарант с полным текстом статьи (только короткий span в dialog).

### Сильное / слабое / берём / превосходим (чат + flows)

| | |
|---|---|
| **Сильное** | Продуктовая ось «ссылка/цитата»; умная папка как закрытый корпус; flows снижают friction формулировки; follow-ups и фидбек; явные статусы доступа к источникам в тарифе |
| **Слабое для ПСБ** | Auth-only in-app; Гарант + веб против ТЗ; нет fail-closed «чего не хватает»; flows = generative doc/реклама/ASR шире MVP; purple brand |
| **Берём (идеи, не UI)** | Evidence рядом с ответом; framing KB как «корпус»; empty-state стартовые вопросы; *опц.* короткий каталог банковских запросов **после** verify; дисклеймер помощника |
| **Превосходим в MVP** | Только выданная KB; статусы `grounded/limited/abstain/clarify` + missing; программный verify; панель «Подтверждения» со span; роль банковского юриста / редакции / jailbreak |

### Опциональные улучшения LegalChat (docs only, не копировать Яндекс / не purple)

1. **Follow-ups после `grounded`** — 1–2 чипа уточнений строго по KB (у них 3 крупных чипа; у нас усилит демо без расширения скоупа).
2. **Empty-state → «типовые запросы кейса»** — 3–5 кликабельных вопросов из фикстур (лёгкий аналог flows-каталога, не wizard/мультиагент/OCR/ASR).
3. **Cite → dialog/панель span в «Подтверждениях»** — у них dialog «Источник» с коротким фрагментом; у нас сильнее: claim↔span + missing + статусы `grounded/limited/abstain` (их fail-closed abstain UI **не видели**).

## Выводы для нашего решения

1. Центр продукта — **verify layer**, не красивый промпт и не каталог flows.
2. UI обязан показывать **фрагмент-доказательство**, иначе экспертный критерий «достоверность» не закрыть визуально.
3. Мультиагентность допустима (retrieve / judge), но только если не убивает latency онлайн-этапа.
4. Не гнаться за «умным советником шире базы» — ТЗ это прямо запрещает.
5. NeuroLegal подтверждает рынок «ссылки + своя БЗ» и паттерн project/chat/flows, но **не** задаёт скоуп MVP: у нас уже база кейса, без Гарант/Word/мультимодальности/wizard-flows; сила — дисциплина отказа и цитирования.
6. Live `/expert/*` (2026-11-09): цитаты + dialog «Источник», панель источников умной папки, каталог flows — **зафиксированы**; abstain/refuse UI — **не пойман**. Без сессии Passport агент снова упрётся в стену.
