# ГАРАНТ (`base.garant.ru`) — источник и границы для ПСБ

> Дата проверки: 2026-11-09  
> Статус: intake note (не интеграция)

## Что это

- **ГАРАНТ** — коммерческая информационно-правовая система (ООО «НПП „ГАРАНТ-СЕРВИС“»).
- **`https://base.garant.ru/`** — веб-витрина / каталог документов системы: кодексы, ФЗ, подзаконка, «горячие» акты, бизнес-справки, ленты новостей/аналитики, формы.
- На портале продвигают собственный ИИ **«ИСКРА»** (ответы по базе ГАРАНТ) — рыночный аналог Legal RAG, **не** наш runtime-источник.

## Модель доступа (факт с витрины)

| Режим | Что видно |
|---|---|
| Публичный каталог | Навигация, поиск, часть карточек/текстов документов по прямым URL |
| Демо | CTA «Получить демо-доступ» / «Демо-доступ на 3 дня» |
| Полный комплект | CTA «Купить систему ГАРАНТ», «Узнать стоимость» — **платная подписка** |
| API | **Гарант Коннект** (`api.garant.ru`): поиск, экспорт PDF/RTF/ODT/HTML, гиперссылки — **по OAuth/токену подписчика** (B2B-договор) |

Легальный экспорт документов для подписчиков существует в UI («Сохранить в файл»: PDF / RTF / ODT) и через API Коннект. Без подписки / договора — полного массового выгруза нет. Материалы портала защищены правилами использования (письменное разрешение правообладателя на большинство сценариев; запрет собирать составные БД из материалов без разрешения).

**Не делаем:** scraping, обход paywall, credential stuffing, «скачать всё с base.garant.ru» без лицензии.

## Связь с хакатонным проектом ПСБ

| Контур | Правило |
|---|---|
| **Демо / сабмит / судья** | Только **KB организаторов**. Юр. утверждения бота **не** опираются на ГАРАНТ, веб или live-fetch. |
| **Runtime ответа** | Никаких вызовов `base.garant.ru` / `api.garant.ru` / ИСКРЫ. Fail-closed RAG по локальному индексу. |
| **Обогащение корпуса (пост-MVP / вне сабмита)** | Допустимо **только если**: (1) у команды есть **законный** доступ (подписка/договор/экспорт UI или Коннект), (2) **организаторы явно разрешили** расширить корпус, (3) файлы уже лежат **локально** → offline ingest в fixtures/pgvector. Цитировать «веб ГАРАНТ» в ответе нельзя. |
| **Аналоги** | NeuroLegal продаёт Гарант как add-on для цитат — у нас **наоборот**: закрытая KB кейса + verify. См. `ANALOGS.md`, `DECISIONS.md`. |

## Типы контента (релевантно LegalTech)

- НПА: кодексы, законы, указы, постановления, приказы, указания ЦБ.
- Справочные блоки, бланки, классификаторы.
- Комментарии / экспертные материалы ГАРАНТ (часто в платном контуре; HTML-экспорт API может включать комментарии).
- Судебная практика и аналитика — на витрине как отдельные ленты/разделы.

Для кейса ПСБ первичен **выданный организаторами** набор положений; ГАРАНТ — внешний vendor корпуса, не часть MVP.

## Опциональный offline-ingest (если файлы уже легально получены)

> Только outline, без кода. Вход: локальные `pdf` / `docx` / `html` в `data/` (не live URL).

1. **Drop** — положить файлы в `data/garant_raw/` (или согласованный каталог); зафиксировать provenance (договор/экспорт UI/дата).
2. **Parse** — извлечь текст + метаданные (название, номер, дата редакции, источник файла).
3. **Chunk** — чанки с id документа / раздела / редакции (как у KB кейса).
4. **Embed** — BGE-M3 → pgvector (тот же пайплайн, что для организаторской базы).
5. **Tag corpus** — метка источника (`case_kb` vs `enrichment`); в хакатонном режиме enrichment **выключен** для судьи/демо.
6. **Never** — runtime fetch, цитата URL ГАРАНТ как обоснование claim.

## Вывод BA

ГАРАНТ — зрелый **corpus vendor** с легальным экспортом для подписчиков.  
Для Hack&Change × ПСБ он **не** заменяет KB кейса и **не** подключается в runtime. Любое использование — только offline, по лицензии и с разрешения организаторов.
