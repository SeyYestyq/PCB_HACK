# Где ключи LLM организаторов (Hack&Change × ПСБ)

> Ответ на вопрос «не могу найти API-ключи организаторов». Источники: Технический регламент §6–7,9; sample README / `solution.py`; кейс §Ограничения 01, 14.

## 1. Есть ли ключи в drive-пакете?

**Нет.** В скачиваемой папке организаторов (`Данные` / `data/organizer/`) ключей нет и не должно быть:

- `kb/`, `knowledge-base.zip` — база знаний
- `sample/`, `sample_submission.zip` — стартер `solution.py`
- `tests/demo_*.csv` — демо-вопросы/ответы
- `docs/*.docx` — техрегламент
- `requirements.txt`

Регламент §4: «Не включайте в материалы действующие ключи, пароли и закрытые ответы.»  
Кейс: «Нельзя размещать в репозитории API-ключи и другие секреты.»

## 2. Когда и откуда появляются ключи

**Только на платформе хакатона при runtime** автоматической проверки. Платформа сама инжектит env в Docker-контейнер сабмита.

Цитата, Техрегламент §6:

> «Участникам не нужны собственные API-ключи. Для генерации, эмбеддингов и реранжирования используется один локальный OpenAI-совместимый прокси: платформа автоматически передаёт его адрес и служебный API-ключ через переменные окружения.»

> «`LLM_BASE_URL` или `OPENAI_BASE_URL` — … платформа подставляет автоматически.»  
> «`LLM_API_KEY` или `OPENAI_API_KEY` — служебный ключ … платформа подставляет автоматически.»

Sample: «Настройки приходят с платформы. В ZIP НЕ НУЖНО класть секреты и .env.»

Значения ключа **не выдаются** участнику для копирования в личный `.env`. Менять служебный ключ не нужно (§9: при `401 / token_not_found_in_db` — сообщить организаторам).

## 3. Что делать сейчас без ключей организаторов

1. Писать `solution.py`, читающий `LLM_BASE_URL` / `LLM_API_KEY` (или `OPENAI_*`) из env — как в `data/organizer/sample/solution.py`.
2. Локально — **свои** модели (кейс §Ограничения 01: «При разработке и локальном тестировании решения участники могут использовать любые доступные им языковые модели»). Например OpenRouter / Yandex Cloud grant — только local/dev; см. `LLM_API_SCOPE.md`.
3. Прогонять на `data/organizer/kb` + `tests/demo_questions.csv`.
4. Сабмит ZIP на платформу — ключи подставятся сами.

## 4. Где смотреть на Changellenge / Hack&Change

В пакете и регламенте **нет** описания UI «скачать / скопировать API-ключ».

Что есть в регламенте про платформу:

- загрузка ZIP-сабмита (`solution.py` + `requirements.txt`);
- «Кнопка для сабмитов»;
- лидерборд / статус проверки («Решение находится на проверке»…);
- при ошибке доступа к API — писать организаторам, ключ самому не менять.

**Не искать ключ в drive и не ждать отдельной выдачи ключа в ЛК** — по тексту регламента его инжектят только в runtime контейнера.
