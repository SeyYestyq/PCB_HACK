## Когда запускать

1. После первого UI чата / экранов ассистента.  
2. Перед демо и финальной сдачей.  
3. По запросу «unslop / убери AI-вид».

## Порядок в этом проекте

1. Прочитать `skills/unslop/SKILL.md` + `references/signs.md`.  
2. Audit → Direction (5 строк) → стоп, если пользователь не сказал «делай».  
3. Девять passes по скиллу.  
4. Для ПСБ: character вокруг **доверия юриста банка** — спокойный chrome, акцент на цитатах и фрагментах доказательств, без purple gradients / glow / emoji badges.

## Не делать

- Не переписывать продуктовую логику RAG/отказов ради «красоты».  
- Не тащить визуал чужого демо из stubs (beauty/налоги) в UI юриста.
