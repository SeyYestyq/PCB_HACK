## Что за вами и в каком порядке делать

1. D3, D2, D4: сабмит вообще запускается на платформе (плоские модули в корне, `python solution.py` без аргументов пишет `submission.csv`, база из `DATA_DIR/knowledge-base.zip` с запасными именами). Смоук `RG-SUB-01`.
2. D22: изоляция вопроса, проверка входов до открытия файла, атомарная запись, одна строка на ID (`RG-DEF-D22`, `RG-SUB-04`, `RG-SUB-05`, `RG-SUB-09`).
3. R1.8 и D18: уточнение по каталогу контрагентов (ключи «номер договора» и «ИНН»), а не по кавычкам.
4. Ранжирование: нужные пункты в первых трёх цитатах; Q12 не должен ссылаться на НК ст. 284 вместо ТК ст. 70.
5. Дальше по ТЗ: история в пайплайне (D19), лимит 4000, редакции, проверка цитат, инъекция ЮО-7 только как данные, SSE, секреты не в логах.

Модули `psb_guard`, `psb_query`, `psb_catalog`, `psb_editions`, `psb_decide` - только предложения узлов, их принятие идёт через `DECISIONS.md`. Код в этом пакете не содержится и не правится отсюда.
