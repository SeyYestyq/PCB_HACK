# С чего начать

Это пакет документации для ИИ-ассистента юристов банка (Hack&Change 2026 × ПСБ), версия 1.6, собранный 10 ноября 2026, около 07:23 мск (Europe/Moscow). Исходный архив `PSB_Legal_Assistant_docs_pack.zip` разложен по ролям: у фронтенда, ядра и роли по базе свои папки с ТЗ, тестами и ревью. Дубли между папками сделаны специально, чтобы агенту роли можно было отдать её каталог целиком.

Официальный кейс (PDF и текст) лежит в `01_common/official_case/`. Это источник истины по условиям. Документы «Бизнес: Старт» в репозитории к этому продукту не относятся.

## Порядок работы сейчас

Актуально на 10.11.2026. Подробности в последнем разделе `STATUS.md`.

1. Роль 1 закрывает запуск сабмита на платформе: D3 (плоские модули `psb_*.py` в корне, без импорта из `apps/`), D2 (`python solution.py` без аргументов сразу пишет `submission.csv`), D4 (база из `DATA_DIR/knowledge-base.zip`, запасные имена `kb.zip` и `knowledge_base.zip`). Смоук: `RG-SUB-01`.
2. Сразу после этого D22: отказ одного вопроса изолируется, база и `questions.csv` проверяются до открытия выходного файла, запись через временный файл и `os.replace`, одна строка на ID. Тесты: `RG-DEF-D22`, `RG-SUB-04`, `RG-SUB-05`, `RG-SUB-09`.
3. Затем R1.8: неоднозначность контрагента по каталогу с ключами «номер договора» и «ИНН», а не по кавычкам (дефект D18).
4. Затем ранжирование: нужные пункты должны попадать в первые три цитаты (сейчас это стабильно только у Q8; Q12 цитирует НК ст. 284 вместо ТК ст. 70).
5. Роль 2 параллельно: композер (кнопка «Остановить», `aria-disabled`, без точек «печатает»), экраны и кнопки по полному ТЗ, проверка SSE по одному событию (`CN-SSE-04`).
6. Роль 3 параллельно: содержательные оракулы `must_cite` и `must_not_include` по 18 вопросам, golden, формула судьи из `07-tests/04` §6 п. 6. Стартовые вопросы пустого экрана подтверждает роль 3 после R1.3 и R1.5-R1.7.

## Что агенты не сделают сами

По этим файлам агенты могут написать код, тесты и интерфейс. Сами они не закроют следующее, это остаётся за командой:

- Живой ключ LLM и прогон на нём. В пакете есть только лексический прогон as-is без модели (`07-tests/artifacts/asis-d1f068c-lexical-run.md`). Метрик живой модели нет.
- Открытый вопрос про код ошибки лимита 4000 символов: в тестах 422, в `02-architecture/01` §5.1 указано 400. Нужно решение команды (и при необходимости вопрос организаторам).
- Трактовка статуса `clarify` платформенным судьёй не подтверждена.
- Ручная проверка `RG-A11Y-08` (доступность, которую автотест не закрывает).
- Тест `RG-PERF-01` в каталоге сознательно не заведён. Замер производительности ещё предстоит спланировать и сделать.
- Прав на запись в GitHub `SeyYestyq/PCB_HACK` нет (`push: false`). Публиковать код может только тот, кому владелец даст доступ. Ничего не пушить без этого доступа.

## Как пользоваться ссылками внутри файлов

Исходные документы не переписывались. Внутри них относительные пути такие же, как в старом пакете: например `01-product/08-tz-frontend-complete.md` от `docs/INDEX.md`, или `../STATUS.md`. Из папки `00_START_HERE/` эти ссылки сами не откроются.

Оригинальные пути сохранены внутри ролевых папок (`02_frontend/docs/...`, `03_backend_rag/docs/...` и так далее). Полный набор тестов и ревью без выборочного отбора лежит в `05_review_and_tests/docs/07-tests/` и `05_review_and_tests/docs/08-review/`. Если ссылка из `INDEX.md` не открывается, найдите тот же относительный путь в `MANIFEST.md`.
