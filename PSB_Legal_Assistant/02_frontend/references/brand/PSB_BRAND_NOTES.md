Это не страница самого банка, а копия руководства. Токены ниже совпадают с разделом 02.10–02.12 PDF. Не заменять их значениями с логотип-агрегаторов (например Trace Logo’s даёт другие hex, их не использовать как канон).

## Цвета (экран: RGB из раздела 02.10)

Основные:

- Синий, Pantone Blue 072C, RGB 043 / 44 / 132, HEX `#2B2C84`
- Оранжевый, Pantone 172C, RGB 234 / 86 / 20, HEX `#EA5614`
- Белый, RGB 255 / 255 / 255, HEX `#FFFFFF`

Дополнительные:

- Серый, Pantone 431, RGB 100 / 104 / 114, HEX `#646872`
- Зелёный / хаки, Pantone 5753C, RGB 78 / 98 / 28, HEX `#4E621C`

Depot WPF (агентство ребрендинга, 2019, https://www.depotwpf.ru/portfolio/psb/): основным назначили синий, оранжевый оставили для акцентов. Кодирование направлений: розница, синий; МСБ, серый; гособоронзаказ, хаки. Для юридического ассистента банка логичная база, светлый холст, синий как primary, оранжевый только как редкий акцент, не как «AI-фиолетовый» и не как заливка всего интерфейса.

## Шрифты (02.11–02.12)

- Основной: Gilroy. Semibold для заголовков и акциденции, Regular для наборного текста.
- Запасной, если Gilroy недоступен: системный Verdana (Bold / Regular).

В PDF прямо запрещено менять цветовой код логоблока, красить логотип в оранжевый, менять гарнитуру логотипа, ставить его на чужеродные фоны.

## Что не делать

- Не брать палитру «Бизнес: Старт» и Alfa-красный `#EF3124`.
- Не подменять официальный синий/оранжевый «похожими» значениями с сайтов логотипов без сверки с брендбуком.
