# Роль 2: фронтенд

Вы делаете веб-чат `apps/web`: экраны, кнопки, состояния, доступность и соответствие брендбуку. Ядро и базу не реализуете, но обязаны соблюдать контракт API.

## Что читать и в каком порядке

1. Полное ТЗ: `docs/01-product/08-tz-frontend-complete.md` (экраны S0-S12, кнопки K1-K10, элементы FE-*).
2. Карточки задач: `docs/01-product/05-role-2-frontend.md` (R2.1-R2.11).
3. Узел ND8: `docs/06-nodes/08-frontend.md`.
4. Бренд и UI по порядку: `docs/04-brand/01` ... `07`, плюс PDF `pdf/PSB_Legal_Assistant_Brandbook.pdf`.
5. Ревью фронта: `docs/08-review/02-frontend-design-review.md`.
6. Тесты, которые вас касаются: `docs/07-tests/00-strategy.md`, `02-regression.md` (блоки UI и a11y), `03-unit-and-contract.md` (контракт API → экран). Полный каталог есть в `../05_review_and_tests/`.
7. Фон: `docs/01-product/03-tz-roles-3-people.md`, передачи `07-handoffs-and-interfaces.md`, API в `docs/02-architecture/01-system-architecture.md` §5.
8. Цвета: прогон `tools/contrast.py`. Официальные гайды ПСБ в `references/brand/` и `references/psb/` не править.

## Что за вами

Композер «Спросить» / «Остановить», поле ввода и лимит 4000, чипы источников, панели и просмотр документа, уточнение, плашки статусов, прогресс SSE, пустые и ошибочные состояния, тёмная тема по системной настройке, a11y. Сейчас в приоритете: поле и кнопка не блокируются на время ответа, кнопка становится «Остановить»; «Спросить» неактивна только в пустом поле и при превышении 4000 знаков, через `aria-disabled`; без точек «печатает», посимвольной печати и пузырей справа (D27, RG-UI-*, BJ-07). На compose проверить, что события SSE приходят по одному (`CN-SSE-04`). В `docker-compose.yml` для `web` не задан `API_UPSTREAM` - это нужно учесть. Спека `e2e/masha.spec.ts` ещё ждёт «Бизнес: Старт» и уже не проходит.

## Передачи

- От роли 1: схема `AnswerV2`, статусы, `reason`, флаги, SSE (H-01 и соседние в `07-handoffs-and-interfaces.md`). Не выдумывать поля.
- К роли 1: баги контракта и рассинхрон UI с API.
- К роли 3: тексты пустого экрана и стартовые вопросы (их подтверждает роль 3 после правок ранжирования и меток). Список стартовых вопросов сейчас не даёт верной цитаты.
- Ревью: `08-review/02`, плюс общие правила в `../05_review_and_tests/docs/08-review/00-overview.md`.

## Готово, когда

Закрыты карточки R2.* и критерии FE-* из полного ТЗ; экраны S0-S12 и кнопки K1-K10 соответствуют брендбуку; контрактные и UI/a11y тесты из вашего набора зелёные. Исключения, которые агент сам не закроет: ручная проверка `RG-A11Y-08`; живой ключ LLM для сквозного прогона чата; спор 422 против 400 на лимите длины (открытый вопрос команды).
