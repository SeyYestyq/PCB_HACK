# 05. Анти-слоп и тренды: что отвергаем, что берём

Цель: интерфейс должен выглядеть как рабочий инструмент юридического департамента банка, а не как очередной AI SaaS. Метод: каждый тренд проверяем тремя вопросами.
1. Помогает ли он юристу **проверить** ответ (кейс, критерий «Реализация контроля достоверности» 25%)?
2. Совместим ли он с брендом ПСБ (гайд: синий основной, оранжевый для акцентов; запрет эффектов на логотипе)?
3. Проходит ли он HIG и WCAG 2.2?

Если хоть один ответ «нет», тренд отвергается.

Источники для аудита: `skills/unslop/SKILL.md` и `skills/unslop/references/signs.md` в репозитории (автор Damir Sokolovsky, CC BY 4.0), `docs/design/09-unslop.md`, визуальные референсы `/workspace/pcb/refs/` (манифест `refs/MANIFEST.md`), снимки `references/psb/`.

## 3. Почему это не «скучно»

Характер создают не декор, а три фирменных приёма, которых нет у типового AI-чата:
1. **Двойной шрифт смысла**: засечки означают «слова документа», гротеск означает «слова ассистента».
2. **Отказ как полноценный экран** с перечнем недостающего, а не как текст ошибки.
3. **Бренд ПСБ через дисциплину цвета**: синий 072C у одного действия и у выделения доказательства, оранжевый 172C только там, где нужно внимание. Так это сформулировало агентство Depot, автор ребрендинга 2019 года (B3 в `01` §4.1): «Основным "назначили" синий, а оранжевый использовали для расстановки акцентов».

## 4. Чек-лист unslop перед демо

Пройти по `skills/unslop/references/signs.md` все группы и подтвердить:
- [ ] Нет градиентов, свечений, glass, blur-пятен.
- [ ] Один акцент на экран: одна primary кнопка.
- [ ] Веса шрифтов только 400/500/600, нет uppercase с разрядкой, нет курсива для акцента.
- [ ] Иконки одной библиотеки, одного размера в ряду, без эмодзи и искр.
- [ ] Все отступы на 4-шкале, одинаковая высота строк в списках.
- [ ] Нет приветствий, восклицаний, «упс», хайп-слов, точек в подписях кнопок.
- [ ] Каждый статус: иконка + текст; контраст текста ≥ 4.5:1, границ ≥ 3:1.
- [ ] Все интерактивные элементы: hover, pressed, focus-visible, disabled; L-цели 44px.
- [ ] Длинное тире (U+2014) в интерфейсных строках не используется.
- [ ] Ничего из наследия: `#EF3124`, platinum, lavender, Manrope, `public/icons/3d`.
