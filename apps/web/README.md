# Веб-чат юриста

React 19 + TypeScript + Vite. Стилизация — собственная дизайн-система на CSS-переменных (`src/index.css`), иконки — `lucide-react`, шрифты — локальные Manrope и Source Serif 4. Внешних CDN нет: сборка работает в закрытом контуре и в Docker без интернета.

Tailwind не подключён осознанно: экран один, типографика и состояния вердикта плотно кастомные, слой токенов в CSS даёт то же без дополнительного build-шага и конфликтов с `nginx`-раздачей.

Браузер всегда отправляет `POST /api/v1/ask` на тот же адрес, с которого открыт чат.

## Локально

Сначала поднимите API на `http://127.0.0.1:8090`.

```bash
cd apps/web
npm install
npm run dev
```

Чат: http://localhost:3000

Vite проксирует `/api` на `http://127.0.0.1:8090`.

```bash
npm run build     # tsc --noEmit && vite build
npm run preview   # статика на 3000 + прокси /api
npm run test:e2e  # Playwright, e2e/legal.spec.ts
```

## Docker

Образ собирает фронт на `node:22-alpine`, затем `nginx:alpine` раздаёт `dist` на порту 3000, `/api/` проксируется на `http://answer:8090/api/`.

## Компоненты

| Файл | Ответственность |
|---|---|
| `src/components/LegalChat.tsx` | состояние диалога, отправка вопросов, синхронизация активной цитаты, счётчики сессии |
| `src/components/Sidebar.tsx` | тёмный навигационный контур: бренд, «Новый диалог», примеры, границы базы |
| `src/components/Topbar.tsx` | контекст, состояние базы знаний, действие; единственный `h1` страницы |
| `src/components/Intro.tsx` | первый экран: герой-карточка, три сценария (включая отказ) |
| `src/components/AnswerCard.tsx` | вердикт-штамп, проходы-цитаты, «чего не хватило», копирование |
| `src/components/EvidenceRail.tsx` | источники, сгруппированные по документу, и «паспорт сессии» |
| `src/components/Composer.tsx` | поле вопроса: автовысота, Enter/Shift+Enter, лимит символов |
| `src/lib/answer-format.ts` | разбор ответа по маркерам `Согласно … (пункт)`, числительные, формат времени |
| `src/lib/legal-api.ts` | контракт `POST /api/v1/ask` |
| `src/lib/brand.ts` | продуктовые строки и примеры запросов |
| `public/fonts/` | локальные woff2 (Manrope, Source Serif 4) |

## Визуальные решения

- Палитра ПСБ: синий `#2B2C84` — основной, оранжевый `#EA5614` — только предупреждения и отказы, светлый холст `#F4F5F9` и бумажные карточки.
- Тёмный сайдбар и светлая рабочая зона: навигация отделена от чтения длинных правовых текстов.
- Вердикт ответа — штамп с цветовой семантикой: подтверждено / частично / отказ / вне компетенции.
- Источники сгруппированы по документу, фрагменты нумерованы и связаны с проходами в ответе.
- «Паспорт сессии» показывает реальные счётчики: вопросов, цитат, среднее время ответа.
- Текст ответа не переписывается: он режется по собственным маркерам ядра, цитаты остаются дословными.
- Движение только по делу: появление реплик, hover-подъём карточек, шиммер скелетона; `prefers-reduced-motion` отключает всё.
